The native `/rsi` entry now controls a durable research responsibility. Its agents
select concrete work, explicit returns, checks, context revisions and waiting through
the existing Operations/store interfaces. The completed qualification used the full
200-case campaign corpus and then exercised the resulting research and task strategies
with real GPT-5.6-Luna/max invocations. It ends in a deliberate inert wait with no
active or unresolved operations.

The new code retains the [layer agreement](PROCONTRACT_LAYERS.md): kernel semantics
are unchanged; harness supplies execution, custody and truthful interfaces; prompts
choose the investigations and workflow. No second RSI kernel, fixed research-stage
sequence, test-count gate, review quota or mandatory global deadline was introduced.

## Corrections and limits retained

This was an iterative, reviewed execution. Operator/Astra audits supplied explicit
counterevidence and a reviewed source specification; the record does not represent
an unattended loop that independently discovered every defect.

A mandatory strategy-specific `current_view` and a later guard for an impossible
mocked state were rejected. The original pending-output path worked. A producer
self-wait, an underallocated 20-second return and incorrect policy-content selection
also remain recorded. These prompted precise responsibility/context corrections,
not automatic watchdogs or new kernel gates.

The last validator initially compared the original producer's input hash with a
same-named later request, and accepted a large wrong number as rendering noise.
Real positive/negative controls refuted those interpretations. RSI repaired the
comparison rule and explicitly bound historical producer inputs; the good 200-row
artifact was preserved throughout.

All native calls, including incomplete/cancelled/expired calls, remain accounted:
v6 154, v7 336, v8 317 (807 total). Operator/development-agent inference is outside
that native ledger. Native work used GPT-5.6-Luna/max, offline execution, no request
ceiling and no standing deadline; actual action/environment allocations were retained.

Corpus coverage is the full census/index plus accumulated case studies and corrected
interpretations; detailed semantic coverage is recorded in the retained synthesis.
This qualification establishes execution integrity, actual context use and the scoped
artifact/validator results. It does not produce a new ProgramBench score or establish
a causal general strategy-performance gain. Original benchmark runs, resource regimes,
failed attempts and the separate stgit retry remain unchanged.
