# Eight retained-artifact score recoveries

The user authorized repair and re-evaluation of Felix, Oha, masscan, dutree, age,
xplr, pls and Broot. Deployment/evidence live at
`/data/ProContract/programbench-sol61-score-recovery-20261106/`. These are grading
jobs on retained artifacts; no model execution or renewed solver grant is involved.

## Failure and repair

Five archives contain ordinary FIFOs used during filesystem observations. The
pinned extractor rejected all special members, preventing compilation. Felix has
relative paths up to4086 characters; prefixing `/workspace/` exceeded PATH_MAX.
The new adapter restores objects through directory descriptors, retaining FIFO,
symlink and hardlink identities, content, modes and timestamps. It does not follow
archive symlinks while writing, change member names, or discard troublesome files.
It runs inside the existing capability-restricted offline compile container.

Oha's first container-stop observation failed, but the retained final observations
show native shutdown exited and no remaining executor. A stale earlier error
prevented submission capture. The original stopped workspace was recovered from
its hash-bound retention archive and compared with GNU tar before packaging under
the original exclusions. Original events and allocation records remain intact.
The independent retry driver already evaluates final shutdown/cleanup facts before
capture; this recovery uses the same distinction without restarting the solver.

Age is a source-namespace collision, not simply a missing observer receipt. Official
`eval/run.sh` builds auxiliary programs from its supplied Go source before invoking
pytest. Candidate `package main` files remained beside that `package age` source,
so helper compilation failed before pytest could write a scope receipt. The receipt
error therefore hid an earlier concrete failure.

The trusted grader registry now exposes `test_workspace: isolated` as an explicit
capability; the default remains `inherit`. Isolation retains the entire build tree
outside the test source workspace and leaves the evaluator's stashed compiled
subject and system dependencies intact. Official test archives then populate their
own source tree. Only age selects it in this recovery profile: its compile output
is a single Go executable using system OpenSSL; fixed text resources are embedded.
This choice is pinned and is not inferred by the harness from score or task name.
Tests, test identities, assertions, retry policy and scorer are unchanged.

## Controls and provenance

Controls cover FIFOs, exact modes, hardlinks including forward references, preserved
external symlink targets, rejected writes through symlinks, and paths beyond4096
bytes. Felix's real13063-member archive restored completely in a real offline
container with all capabilities dropped. A real Go container control fails when
candidate/helper packages share a source tree and succeeds with isolated sources,
while retaining the old tree and the exact compiled-subject hash. Private-container
timeout cleanup and pytest observer controls also pass.

The initial isolation control exposed overlay-directory rename returning EXDEV.
The repaired implementation retains the tree with `cp -a` before clearing only the
private test workspace. Both diagnostic attempts remain in the evidence directory.

The recovery plan binds new adapter source and original artifact/budget hashes.
Pinned images are imported with verified original config bytes and RootFS layers;
compilation is offline and testing uses the qualified grader bridge. All eight jobs
share the existing total capacity16, initially reserving two admissions. New scores
are separate measurement records, preserving every original failure and raw score.

These fixes belong to harness artifact/measurement transport. They add no progress
threshold, task-solving workflow or kernel transition. The parallel Astra report is
at `/data/ProContract/procontract-sol61-rsi-retro-20261106-astra/`; its strategy
candidates remain research records rather than silently promoted runtime policy.
