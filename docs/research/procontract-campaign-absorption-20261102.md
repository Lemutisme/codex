## What is being absorbed

The existing H1–H3/S1–S3 organization survives the larger corpus. Successful work
builds an expressive implementation, reaches meaningful behavior with an observation
tool, repairs shared rules/state transitions, and carries useful assets and knowledge
into later work. Shellharden, loop, hex, ZIP, pingu, controlled servers and the PTY
repair provide different manifestations; neither long iteration nor early rest is
universally necessary.

Weak trajectories reveal distinct limits: observations silently narrowing the goal,
local residuals displacing missing capabilities, probes stopping before the intended
path, unsupported interpretations of current state, and execution/evidence boundaries
that prevent continuation. Keep artifact quality, observation validity, execution
status and formal acceptance separate. The score itself does not identify a cause.

New contrasts sharpen the mechanisms:

- CMatrix implements actual terminal state and uses curses/terminfo and a PTY probe.
  Internal comparisons move from 16/70 to 69/70, while its final eligible result is
  506/506. A late internal timing residual remains recorded. This is useful cumulative
  work without certifying that every review contributed to the perfect result.
- Pueue's final ordinary-command path always calls `backend_error`, including a
  communication error when a socket exists. Internal comparisons improve 66/82 to
  75/82, but no successful daemon communication is implemented; the result is 115/638.
  The executor actually searched for `pueued` and found none. The diagnosis is not
  "forgot to search": availability, method feasibility and narrowing the intended
  outcome require separate analysis.
- FFmpeg contains real WAV/FLAC/PCM work and concrete option/logging defects. Of
  1,091 eligible harvest failures, 1,025 explicitly report missing fate-suite files;
  its source reads those files before codec handling. This locates the observed
  stage, without establishing the full provisioning cause or a corrected score.
- Ctags has substantial parser code but poor output agreement on many actual
  harvested cases. Miller has genuine record/DSL work and reusable regressions,
  alongside unimplemented auxiliary verbs and broader residuals. These contrast
  with missing-input observations: all low scores cannot share one cause.

The actionable consolidation is therefore:

| Layer/direction | General enhancement |
| --- | --- |
| Strategy S1 | Select work by the useful result or consequential decision it can change; keep major unimplemented paths, uncertainty and available resources visible |
| Strategy S2 | Choose/acquire representations and observation capabilities that express/reach the intended behavior; test changed inputs/conditions where transfer is required |
| Strategy S3 | Continue from artifacts plus probes, scoped facts and corrected claims; use a concise current view with access to retained detail |
| Harness H1 | Preserve operation ownership, outcomes and original grants across caller/role/process failure; expose the next authorized choice |
| Harness H2 | Preserve actual invocation, environment, metric and resource scopes; qualify the capabilities needed to reach the intended observation |
| Harness H3 | Make large retained evidence, meaningful differences, input intervals and subject/claim relations usable without losing identity or duplicating work |

No new kernel semantic requirement follows from this analysis. Research method,
workflow composition, hypothesis choice and adoption judgment remain strategy.
The kernel retains domain-independent responsibility/progress and authorized
transitions. Real tasks can use network, documentation, libraries, services,
computation and authorized collaboration; the offline/clean-room/six-hour profile
is not a universal strategy. A continuing task need not have a hard deadline.

## Giving the process to RSI

`strategies/research/trajectory_analysis.md` is a reusable context-level research
method: inspect the whole declared population and accumulated work, choose useful
contrasts, trace action→observation→change→later behavior, inspect contrary evidence,
retain scoped mechanisms and refutations, and propose precise changes/validation
at the correct layer. It also asks the analyst to examine its own missed evidence
and incorrect assumptions. It imposes no universal phase loop, sample count,
numerical gain gate or mandatory patch.

`scripts/run_procontract_research.py` provisions arbitrary evidence bundles/context,
executes one caller-selected pending-input action using the existing native adapter,
and exports retained knowledge and its cited closure. The work sequence is supplied
context. `scripts/programbench_research_corpus.py` is the separate benchmark data
adapter; it does not infer root causes or choose research strategy.

The first prepared intake retained all source data but its native setup failed
